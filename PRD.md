# Snapshot — Product Requirements Document (PRD)

**Version:** 1.0  
**Date:** July 19, 2026  
**Status:** Draft — Awaiting Approval

---

## 1. Executive Summary

**Snapshot** is an AI-powered Tech Super App that consolidates every major workflow a developer, student, or tech professional needs into a single mobile application. It replaces the fragmented experience of juggling 15+ separate tools and platforms by unifying news consumption, career growth, learning, project management, and AI assistance into one cohesive, beautifully designed experience.

---

## 2. Product Vision

> "One app to rule every stage of your tech career — from learning your first language to landing your dream job and shipping your next product."

---

## 3. Target Audience

| Persona | Description |
|---|---|
| **CS Students** | Undergraduate/graduate students looking for internships, learning resources, and project ideas |

| **Freelancers / Indie Hackers** | Solo builders who need startup news, project management, and resume tools |
| **Tech Enthusiasts** | Anyone who wants curated tech news and AI-powered research in one place |

## 5. Cross-Cutting Concerns

### 5.1 Authentication & Authorization

| Concern | Implementation |
|---|---|
| Auth Provider | Firebase Authentication |
| Login Methods | Email/Password, Google, GitHub, Apple |
| Session Management | Firebase SDK handles token refresh |
| Protected Routes | GoRouter redirect based on auth state |
| Role-based Access | Future-proof for admin/user roles |

### 5.2 Data Persistence

| Layer | Tool |
|---|---|
| Remote Database | Firebase Firestore |
| File Storage | Firebase Storage |
| Local Cache | Hive (offline cache, bookmarks, drafts, settings) |
| Secure Storage | flutter_secure_storage (tokens, secrets) |

### 5.3 State Management

| Scope | Approach |
|---|---|
| Global State | Riverpod (providers, notifiers) |
| Local State | StatefulWidget / HookWidget |
| Form State | Form + TextFormField with validation |
| Navigation State | GoRouter (declarative routing) |

### 5.4 Networking

| Concern | Tool |
|---|---|
| HTTP Client | Dio |
| Serialization | Freezed + json_serializable |
| Interceptors | Auth interceptor, logging, retry, cache |
| Error Handling | Custom exception classes + Either pattern |

### 5.5 Theming & Design System

| Concern | Implementation |
|---|---|
| Design Tokens | Centralized color, typography, spacing constants |
| Dark/Light Mode | Full support via ThemeProvider |
| Typography | Google Fonts |
| Icons | Material Icons + custom SVG icons |
| Animations | Flutter Animate + Lottie |
| Responsive | Responsive Framework (mobile-first) |

### 5.6 Navigation

| Concern | Implementation |
|---|---|
| Router | GoRouter with shell route for bottom nav |
| Deep Linking | Supported via GoRouter configuration |
| Auth Guard | Redirect unauthenticated users to login |
| Nested Navigation | Per-tab navigation stacks |

## 8. Non-Functional Requirements
